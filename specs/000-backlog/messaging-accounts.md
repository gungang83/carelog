## 1. 왜 지금 정해야 하나

- Carelog가 환자에게 **상담 안내**를 보내기 시작했다(spec 038). 지금은 문자(솔라피)로 나가고, 카카오 알림톡은 코드 준비 완료 — 채널·템플릿만 있으면 켜진다.
- 그런데 계정·채널을 **누구 명의로, 몇 개로, 누가 관리하며, 비용을 누가 내는지**가 정해지지 않았다. 카카오 템플릿은 승인 후 **수정 불가**, 비즈니스 인증은 **사업자 1개 명의**라서 한 번 잘못 잡으면 되돌리기 비싸다(PLAYBOOK §5 "되돌릴 수 있게").
- EO도 같은 솔라피·같은 번호로 문자를 보내고 있다(근로계약서 서명 인증코드). → **제품 공통 자산**이라 Carelog 단독 결정이 아니다.

## 4. 결정 후 할 일 (참고 — spec 038 §7 상세)

1. 카카오비즈니스 통합 계정 → 채널 개설 → 비즈니스 채널 인증(ⓑ 사업자 서류, 영업일 1~3일).
2. 채널 공개 ON · 관리자 추가 인증 · 고객센터 정보 입력 → 솔라피 채널 연동(pfId).
3. 알림톡 템플릿 등록(원고 = spec 038 §7, 도메인 ⓖ 반영) → 카카오 검수(영업일 1~3일).
4. 회사 발신번호(ⓒ) 솔라피 등록 → 템플릿 대체 발송 번호로 지정 + 각 제품 `SOLAPI_SENDER_PHONE` 교체.
5. 다온: Carelog env 2개 + 기본 발신번호 교체 → 재배포 → 대표 번호로 시험 발송. EO 쪽 적용은 오너가 테오와.
