# 백로그 — 상담 품질 평가 (체크리스트 대조) · 기획공장 협업 (대표 발굴 2026-10-18 미팅)

> 출처: 컨설팅 업체 '기획공장' 이정숙 대표 미팅. 상담 내용을 평가 체크리스트와 대조해 부합도를 평가.
> 상태: 기획 초안 — 논점 A~F 대표 확정 대기. 확정 시 spec 034 승격.

## 1. 평가 가능 범위 (대표 질문 회신)

- ✅ **내용**(무엇을 말했나): 통증 확인·옵션 제시·비용/주의사항 안내·질문 응대 — 텍스트로 충분.
- ✅ **언어적 태도**(어떤 말로): 존댓말·공감 표현·쉬운 설명·일방 vs 대화 — "말투"의 어휘적 측면은 전사에 남음 → 평가 가능.
- ❌ **음성적 어조**(톤·부드러움): 전사 소실 — v1 불가. 말 속도는 타임스탬프로 가능(보너스), 화자 분리·어조는 Phase 2(Soniox 등).

## 2. 설계 골격

- **템플릿**: 기획공장 표준 체크리스트(파트너 제공) + 병원별 수정 — spec 029 전역/기관 2층 패턴 재사용.
  항목 = { 이름, 판정 기준 설명, (지침) } — 예: "치료 옵션을 2개 이상 제시했는가".
- **실행**: 상담 기록 카드 [평가] 버튼(수동, v1) → 서버가 전사/본문 + 템플릿으로 Claude 판정.
- **결과**: 항목별 충족/부분/미충족 + **전사 근거 인용(필수 — 신뢰의 핵심)** + 개선 제안. 점수화는 보류(논점 C).
- **데이터**: eval_templates(전역/기관, items jsonb) · eval_runs(consultation_id, template_id, result jsonb, created_by) · RLS 기관 격리.
- **권한**: spec 029 기능 권한 재사용(consult_eval.*). 열람 = 관리자+본인(제안).
- **포지셔닝**: 코칭 보조 도구 — 인사평가 근거 아님(과약속 금지, 현장 반발 방지).

## 3. 논점 (대표 확정 대기)

- A 트리거: 수동부터(제안) / 자동 전건
- B 열람: 관리자+본인(제안) / 관리자만
- C 점수화: 없음+코멘트(제안) / 총점
- D ★기획공장이 평가 결과 열람? — 환자 대화 제3자 제공 → 계약·동의 설계 선행. 이정숙 대표 확인 필요(데이터 설계 분기점)
- E 크레딧: 평가 1회 3(제안)
- F 직원 고지: 기관 설정 on 시 고지 확인 문구 + 클레어(EO HR) 노무 자문 1회

## 4. 로드맵 연결

- '상담 데이터화' 로드맵의 첫 실수요 사례. 추이 대시보드·상담자별 리포트는 B/C 프레임 안정 후 후속.
- 기획공장 = 템플릿·교육 파트너 모델 → 추후 '파트너 제공 콘텐츠' 일반화(상담자료 전역 승격 건과 같은 축).
