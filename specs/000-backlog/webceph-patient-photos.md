# 백로그 — WebCeph 연동: 환자 사진을 상담보드로 (대표 발굴 2026-09-05)

> 아이디어: 덴트웹의 환자 사진을 Carelog 상담보드에서 바로 쓰기.
> 경로: 덴트웹 → [WebCeph 공식 플러그인, 병원 조작] → WebCeph → [파트너 API] → Carelog 픽커.

## 조사 결과 (2026-09-05 다온)

- 덴트웹→WebCeph 플러그인 존재(공식, 단방향 업로드): aligntech-api.webceph.com/hi/plugin/
- **WebCeph 파트너 API 공식 제공**(/hi/api/): 환자 목록·기록 목록·기록 상세(이미지 URL — 세팔로/파노라마, 원본+썸네일)·환자 생성·이미지 업로드. 제3자 파트너 소프트웨어 연동이 명시 목적.
- 인증: 파트너 API Key(파트너에게 발급) + 사용자 API 암호. 한도 30req/min. 병원은 WebCeph Premium 이상 필요.
- 파트너별 전용 인스턴스로 보임(aligntech-api.* = 얼라인테크용).

## 가치

- 상담보드 픽커 "환자 사진" 탭 → 파노라마/구강사진을 스테이지로 크게 열고 그리며 설명 → 기록에 담기.
- 교정과(WebCeph 사용률↑, 사진 중심 상담)에 특히 강력 — 이을치과(천주희) 온보딩 시너지.

## 선행 조건 (착수 게이트)

1. ★**어셈블서클(WebCeph 운영사) 파트너십 문의** — 대표 액션. Partner API Key 발급이 모든 것의 전제.
2. 개인정보 검토 — 환자 의료영상 제3자 제공/위탁(변호사 자문 백로그와 묶기).
3. 병원 측: WebCeph Premium + 플러그인 업로드 습관(자동 아님) — 대상 병원 선별(교정 우선).

## 구현 스케치 (파트너 키 확보 시, 2~3일)

- 서버: WebCeph API 프록시(키 서버 보관, 기관별 사용자 API 암호는 설정에 암호화 저장), 환자 매칭(이름·생년월일/차트번호 → Carelog patient).
- UI: 픽커 "환자 사진" 탭(환자 연결된 상담일 때 노출) → 기록 목록 → 이미지 → 삽입/스테이지.
- 이미지 사본은 기존 consult 업로드 스토리지 정책 준수(외부 URL 직참조 금지 — 만료·권한 문제).
