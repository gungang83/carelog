제목: [파트너십 문의] 치과 상담 기록 서비스 'Carelog'의 WebCeph Partner API 연동 문의

안녕하세요, 어셈블서클 파트너십 담당자님.

치과 상담 기록 SaaS 'Carelog'를 운영하는 SUWANT holdings 대표 송정현입니다.

Carelog는 치과의 환자 상담을 녹음·AI 정리해 상담 기록으로 남기고 환자에게 전달하는
서비스로, 현재 복수의 치과 파일럿을 운영 중입니다. 상담 화면에서 설명 자료·환자 사진을
크게 띄워 그림을 그려가며 설명하고 그 화면을 기록에 남기는 기능을 제공하고 있습니다.

WebCeph의 Partner API 문서(webceph.com의 API 안내)를 보고, 아래 연동을 구상하여
파트너십을 문의드립니다.

■ 연동 시나리오
- 치과가 덴트웹 → WebCeph 공식 플러그인으로 올려둔 환자 촬영 기록(파노라마·세팔로 등)을,
  Carelog 상담 화면에서 해당 환자의 사진 목록으로 조회·표시
- 원장이 사진을 크게 열어 설명하고, 필요 시 상담 기록에 담아 환자에게 전달
- 사용 API: 환자 검색 · 기록 목록 · 기록 상세(이미지 조회) 중심의 **읽기 전용**
  (환자 생성·업로드는 당장 계획 없음)

■ 요청 사항
1. Partner API Key 발급 및 파트너 등록 절차 안내
2. 상세 기술 문서(엔드포인트·인증 방식·에러 규격) 제공
3. 환자 영상 데이터 처리에 관한 계약 조건 협의
   (당사는 개인정보 처리 최소화 원칙으로, 상담에 사용된 이미지만 병원 계정 저장소에 보관합니다)

■ 참고
- 예상 트래픽: 병원당 상담 시 조회 수 건 수준(문서상 30req/min 한도 내 충분)
- 대상: WebCeph Premium 이상 이용 중인 파트너 치과부터 순차 적용
- 서비스: carelog-tau.vercel.app (파일럿) · 병원 인사관리 SaaS 'EO'와 연계 운영

WebCeph의 분석 도구와 Carelog의 상담 전달력이 만나면 교정·임플란트 상담 현장에
서로 좋은 시너지가 될 것으로 기대합니다. 검토 부탁드립니다.
