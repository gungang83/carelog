# spec 030 — 실시간 통역 PoC + 엔진 크레딧 정책

> 상태: **PoC v1 구현(세션 67).** 근거: `specs/000-backlog/o1-multilingual-interpret-feasibility.md`(O-1 Level 2).
> 대표 확정(2026-07-29): 실시간 PoC 진행 · Soniox는 후속 옵션 · 엔진별 크레딧 소모량 차등+표기 · 소진 정책 구상.

## 0. 목표 UX (대표)

> "체어에 앉아서 화면에서 실시간으로 언어가 번역되는 것을 보여주면 좋겠다.
> 그걸 보면서 환자와 서로 이야기하고, 그게 곧 상담 기록으로 남는다."

- 환자와 **화면을 같이 보는** 전체화면 통역 스테이지(큰 글자, 원문 위·번역 아래).
- 종료 시 누적 대화가 `[실시간 통역 — 일시]` 블록으로 상담 기록에 삽입 → 기존 저장 흐름 그대로.
- 기존 MediaRecorder 녹음은 병행 유지 → 실시간이 부실해도 **사후 다국어 전사가 안전망**.

## 1. PoC v1 아키텍처 (하이브리드: 스트리밍 STT + 문장 단위 LLM 번역)

```
ChairProvider getStream() ── 스트림 분기(AudioContext 24kHz → PCM16 → base64)
  → WebSocket wss://api.openai.com/v1/realtime (transcription 세션, gpt-4o-transcribe, server VAD)
      · delta  = 말하는 중 부분 자막(원문, 실시간)
      · completed = 문장 확정 → 서버액션 translateUtterance(Claude Haiku) → 번역 캡션
  → 종료: 누적 쌍 → 에디터 삽입(평문 [라벨]) + 분당 크레딧 기록
```

- **키 보호**: 브라우저는 `/api/realtime/token`(lab 게이트)이 발급한 **ephemeral client secret**만 사용(R6).
- **번역 방향 자동**: 발화가 한국어면 → 영어, 그 외(혼용 포함) → 한국어. 문장 단위 LLM 번역이라
  **코드스위칭(한영 혼용)에 whisper 일괄 방식보다 강함** — 혼용 문장을 통째로 이해하고 번역.
- 순수 실시간 음성번역 모델(gpt-realtime-translate)·Soniox(sub-200ms·혼용 특화·화자분리)는 **Phase 2 교체 옵션** —
  화면·기록 파이프는 provider 무관 재사용. Soniox는 대표 계정 개설 후 같은 스테이지에 엔진 스왑으로 비교.
- 게이트: 실험실(lab) 워크스페이스 전용. 체어 PC 크롬 기준(iPad 백그라운드 제약 동일).

### 구현 파일
| 파일 | 역할 |
|---|---|
| `app/api/realtime/token/route.ts` | lab 게이트 + OpenAI ephemeral secret 발급 |
| `app/actions/interpret.ts` | 문장 번역(Claude Haiku) + 통역 사용량(분당) 기록 |
| `components/chair/interpreter-stage.tsx` | 전체화면 통역 스테이지(부분자막·확정쌍 누적·기록 담기) |
| `components/chair/consultation-board.tsx` | 녹음 중 "🌐 통역" 버튼(lab) + 스테이지 마운트 + 에디터 삽입 |

## 2. 엔진별 크레딧 소모량 (차등 + 표기)

단가 SSOT는 `lib/credits.ts CREDIT_PRICES`. 표시용은 `lib/transcribe/engines.ts LAB_ENGINE_OPTIONS.credits`(동기 유지).

| 엔진/기능 | 크레딧 | 비고 |
|---|---|---|
| 빠른 메모(quick) | 1/회 | 전사만 |
| 기본모델(basic) | 2/회 | 전사+요약 |
| 상세 요약(detailed) | 3/회 | 구조화 |
| 용어 보정(dental) | 3/회 | LLM 2패스급 |
| 다국어(multilingual) | 3/회 | 감지+번역+요약 |
| 비교(comparison) | 5/회 | basic+multilingual 동시 |
| 긴 상담(chunk) | 구간당 1 + 요약 2 | 5분 구간 |
| **실시간 통역(interpret_realtime)** | **분당 1** | 신규 — 세션 종료 시 경과 분 정산 |

- **표기**: 엔진 선택 UI(EngineSelector) 각 pill에 크레딧 뱃지 + 통역 스테이지 진입 시 "분당 1 크레딧" 안내.
- 상품 분화 로드맵(O-1 §7): 기본(Free) / 다국어(Pro) / 실시간 통역(Pro·Ent) — 크레딧 단가가 티어 근거.

## 3. 크레딧 소진 정책 ✅ 확정·구현 (2026-07-29 대표)

**확정**: ① 임박 기준 = **고정 임계(잔액 ≤ 20)** ② 현재 = **(b) 소프트 차단** 구현
③ 정식 서비스화 시 **(a) 전면 차단 전환**(기본 전사 유예를 계속 두면 원가 손실 — 대표 판단).

### 구현 내역 (b + 고정 임계)
- 상수 SSOT: `lib/transcribe/engines.ts` — `CREDIT_LOW_THRESHOLD=20`, `PREMIUM_ENGINE_MODES`(상세·용어보정·다국어·비교), `isPremiumMode()`.
- **서버 게이트(권위)**: ① `transcribeEngine` — 소진 시 프리미엄 모드 **basic 폴백**(녹음 blob 도착 후라 거절하면 기록 유실 — 폴백이 안전) ② `enqueueServerTranscription` — 등록 시점 basic 강등 ③ `/api/realtime/token` — 통역 **시작 403**(진행 중 세션은 중단 없음).
- **UI**: 레이아웃이 잔액을 보드에 전달 → EngineSelector 프리미엄 pill 🔒 잠금 + 소진/임박 안내줄, 통역 버튼 비활성.
- **알림(1일 1회)**: 일일 리포트 cron에 편승 — 전일 활동 기관 중 잔액 ≤ 임계 → owner/admin 알림함(소진/임박 문구, 푸시 억제).

### 원래 설계안 (기록용)

### 3-1. 상태 3단계
| 상태 | 기준(안) | 시스템 동작(안) |
|---|---|---|
| ① 정상 | 잔액 > 임박선 | 설정·홈에 잔액 표시(상시) |
| ② 임박 | 잔액 ≤ 최근 7일 일평균 사용량 × 3일치 (최소 20) | owner/admin 알림함 + 설정 배너 "약 N일 후 소진 예상 — 충전 안내" (1일 1회) |
| ③ 소진 | 잔액 ≤ 0 | 아래 3-2 옵션 |

### 3-2. 소진 시 동작 — 옵션 3안
| 안 | 내용 | 평가 |
|---|---|---|
| (a) 전면 차단 | 모든 AI 기능 시작 불가 | 임상 현장에서 기록 자체가 막힘 — **비추천** |
| (b) 소프트 차단 ★추천 | **프리미엄 엔진(다국어·실시간 통역·상세·용어보정·비교)만 잠금**, 기본(basic·quick)은 유예 허용(마이너스 누적, 배너 안내) | 임상 안전(기본 기록 유지) + 수익 보호(프리미엄 잠금). 실결제 도입 시 기본값 |
| (c) 완전 유예 | 전부 허용 + 마이너스 표시 + 충전 안내만 | **파일럿(현재) 유지안** — 시뮬레이션 단계에 적합 |

### 3-3. 공통 원칙 (어느 안이든)
1. **진행 중인 상담은 절대 중단하지 않는다** — 차단은 항상 "시작 게이트"에서만. 사용 중 잔액이 0이 되어도
   그 세션(전사·통역)은 끝까지 완료하고 종료 시 정산(마이너스 허용). 실시간 통역도 세션 도중 강제 종료 없음.
2. 소진 게이트에 걸리면: 안내 모달("크레딧이 소진되었습니다") + 남은 선택지(기본 엔진 전환/충전 요청) 제시.
3. 시작 전 예상 소모 표기: 엔진 뱃지(회당) · 통역(분당) — 사용자가 소모를 예측 가능하게.
4. 충전 요청 버튼 → 슈퍼어드민 알림(현재 수동 충전 체계와 연결). 실결제는 별도 스펙.

## 4. PoC 검증 계획

1. 예미안/오늘의치과 외국인 상담 1~2건 실측 — 혼용 정확도·지연 체감·마이크 품질.
2. 판정 후: Soniox 비교(대표 계정) → provider 확정 → Phase 2(순수 실시간 스트림 번역·화자 분리).
3. 품질 포지셔닝 유지: 통역은 보조, 최종 기록은 사람 검수.
