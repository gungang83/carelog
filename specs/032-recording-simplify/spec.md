# spec 032 — 녹음 엔진 UX 단순화 (선택 제거 + 자동화)

> 상태: ✅ **구현 완료(세션 68).** 대표 확정 2026-08-16: "1로 가자" — 선택 UI 제거 + 자동화.
> 근거 데이터: credit_log 실사용 46회 중 basic 43(93%) · quick 1 · chunk 1세트 · **상세/용어보정/다국어/비교 = 0회**.

## 1. 원칙

**사용자가 고를 것은 "결과물의 형태"지 "처리 파이프라인"이 아니다.** 엔진 7버튼은 실험
이력의 누적이었고, 신규 사용자에겐 진입 장벽("뭘 골라야 하지?"), 기존 사용자에겐 미사용 장식이었다.

## 2. 확정 설계

| 전 | 후 |
|---|---|
| 홈 히어로: 엔진 7버튼(실험실) | **선택 UI 없음** — [상담 기록 시작] 하나 (+크레딧 소진/임박 안내만) |
| 용어 보정 = 별도 엔진(3크레딧) | **기본 파이프라인 상시 통합** — 같은 AI 호출 1회라 원가 동일, **단가 2 유지** |
| 상세 요약 = 시작 전 선택 | **사후 재요약** — 기록 카드 [📝 상세 재요약](3크레딧): 보관 음성으로 detailed job 등록, 기존 본문 **아래에 append**(덮어쓰기 아님, prefix_html 재사용) |
| 긴 상담 = 수동 선택 | 자동(기존 3분↑ 서버 위임 유지) |
| 다국어 = 수동 선택 | **P2 보류** — 언어 힌트 제거 시 한국어 전사 정확도 회귀 위험, 검증 후. 실시간 니즈는 🌐 통역이 커버 |
| 비교 = 픽커 노출 | 실험실 전용 잔류(보드 idle 픽커) |
| 빠른 메모 | 표면 제거(실사용 1회). 엔진 코드는 보존 — 복원 쉬움 |

- **실험실 구조 보존**: 엔진 레지스트리·lab 게이트·EngineSelector는 코드 유지. 예미안의 엔진 실험은
  '녹음 없이 기록만' → 보드 idle 픽커 경로로 계속(새 엔진 PoC 검증 통로).
- 크레딧: 사용자 표기 단순화 — 상담 기록 2/회 · 상세 재요약 3/회 · 통역 분당 1.

## 3. 구현

| 파일 | 변경 |
|---|---|
| `components/chair/consult-hero.tsx` | EngineSelector 제거, 소진/임박 안내만 잔류 |
| `app/actions/transcribe.ts` | SUMMARY_PROMPT에 치과 용어·치식 교정 상시 통합(runBasic·청크 요약 공용) |
| `app/actions/transcription-jobs.ts` | `requestDetailedResummary` — audio_path 검증·중복 job 방지·prefix_html=현 본문으로 detailed job 등록 |
| `components/consultation/consultation-card.tsx` | 음성 보관 기록에 [📝 상세 재요약] 버튼 + 진행 안내 |

## 4. 후속(P2)

- 다국어 자동 감지(전사 언어 자동 판단 → 번역 패스 자동 포함) — 한국어 정확도 회귀 테스트 선행.
- 사용 데이터 재점검(1개월 뒤): 상세 재요약 사용률로 요약 기본 스타일 재논의.
- dental/detailed/quick 엔진의 레지스트리 정리(코드 다이어트)는 다국어 결론과 함께.
